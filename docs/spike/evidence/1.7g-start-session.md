# 1.7g 能不能用指定內容啟動新 Session

- 執行時間：2026-09-26 08:2x UTC
- 執行者：impl3；容器 `oc17-main`（arm64）
- 判定：**pass**

## 1. 指令與結果

```bash
$ opencode run --title "SPIKE-1.7-G" -m ollama-cloud/deepseek-v4.1-flash \
    "SEED-CONTENT-XYZ: this exact string must appear in the export. Reply ACK."
# rc=0（非互動；指定文字成為新 Session 的第一則 user 訊息）
```

- 新 Session id：`ses_f23463df4ffe9n12PRaV0UZ8z8`。
- 匯出 `Eg.json`：`messages[0].parts[0].text` 逐字含 `SEED-CONTENT-XYZ: this exact string must appear in the export. Reply ACK.`（`grep -c` → 1）。
- 可再被列舉：`opencode session list --format json` 內有該 id；可再被匯出（id 穩定）。
- 取得新 id 的另一條路（供自動化）：`opencode run --format json …` 的第一個事件 `{"type":"step_start","sessionID":"ses_…"}`，不需再查 list。

## 2. 其他相關旗標（當版）

- `--title` 指定標題；`-s/--session <id>` 續接既有 Session；`--fork` 需與 `-c/--continue` 或 `-s` 併用（見 1.7h）。
- `--format json` 輸出 JSONL 事件流（非互動、可腳本解析）。

## 3. 判定

Pass：可用指定內容非互動啟動新 Session，新 id 可確認、內容完整進匯出、可再列舉與匯出。D10／E2E 的開場方式不需改設計。
