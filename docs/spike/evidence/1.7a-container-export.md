## 2. 非互動匯出（完整指令與輸出）

新開測試 Session（容器工作目錄 `/work`，`HOME=/work`）：

```bash
$ opencode run --title "SPIKE-1.7-S1" -m ollama-cloud/deepseek-v4.1-flash "We are testing export stability. Remember the codeword ALFA-123. Reply with one short sentence."
# rc=0（stdout 為人類可讀；`--format json` 則為 JSONL 事件，見下）
```

匯出（`sessionID` 明示）：

```bash
$ SID=$(opencode session list --format json | jq -r '.[0].id')   # ses_f235a894effes0cRw74MxQPLBb
$ opencode export "$SID" > E1.json
# rc=0；bytes=6438；stdout 是單一 JSON 物件（第一個位元組 `{`），stderr 只有一行進度字串
# stderr: Exporting session: ses_f235a894effes0cRw74MxQPLBb
$ jq -e . E1.json >/dev/null && echo parse=OK
parse=OK
```

- `opencode export` 語法：`opencode export [sessionID]`；**無參數時會進入互動選單**（TUI 挑選 session），所以同步器必須明示 sessionID（見共同假綠燈：`Enoarg.err` 顯示互動列表）。不存在的 id → `rc=1`、stderr `Error: Session not found: ses_doesnotexist`（可辨識，非空輸出）。
- 格式：**單一 JSON 物件**，頂層兩個鍵 `info`、`messages`；`messages[i] = {info, parts}`；`parts[].type ∈ {text, reasoning, step-start, step-finish, tool, compaction, ...}`。
- 內容完整性：DB `message` 表列數與 export `messages` 長度一致（SPIKE-1.7-G：DB=2、export=2）。

## 3. 列舉 Session 與 id

```bash
$ opencode session list --format json
[{"id":"ses_f235a894effes0cRw74MxQPLBb","title":"SPIKE-1.7-S1","updated":…,"created":…,"projectId":"global","directory":"/work"}]
```

- `opencode session list --format json` 提供 id／title／時間／目錄；`--max-count N` 可限筆數；`opencode session delete <id>` 可刪。
- 非互動開新 Session 取得 id 的另一條路：`opencode run --format json …` 的第一個事件即 `{"type":"step_start","sessionID":"ses_…"}`（實測）。
- 子 Session 不在 `session list` 內（見 1.7h），須用 `/session/{id}/children`（API）或 `parent_id` 欄位。
