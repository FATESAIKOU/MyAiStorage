## 0. 前置：讀取視圖還沒初始化（fail-closed，預期）

`reader.json` 的 `manifest_file_id` 仍是佔位值（提交流程還沒發佈過讀取視圖），
所以**讀取端一律 fail-closed**：

```
$ docker exec syncer-2 python -m aistorage.syncer opencode once --json
[syncer] AccessDenied: 讀取 manifest 被拒（無 Agora 讀取權）: 找不到檔案 (HTTP 404): PLACEHOLDER-MANIFEST-FILE-ID
RC=1
```

daemon 每一輪都是這樣（`/tmp/aistorage/syncer.log`）：

```
[syncer] daemon 開始，間隔 600 秒
[syncer] 這一輪失敗：AccessDenied: 讀取 manifest 被拒（無 Agora 讀取權）: 找不到檔案 (HTTP 404): PLACEHOLDER-MANIFEST-FILE-ID
```

**這是預期行為，而且方向是對的**：讀不到讀取視圖，就無法確認「這份內容是不是
已經進去」與「上一次上傳有沒有被拒收」，所以整輪不寫任何東西。daemon 記錄
（只有 id 與代碼）後繼續跑，容器與 `opencode serve` 都不受影響
（容器 60 秒後仍在跑，serve 與 daemon 兩個行程都在）。

skill 端也一樣，而且已經是乾淨的訊息而不是 traceback：

```
$ docker exec syncer-2 python -m aistorage.skill find --query "任何東西"
[skill] 讀不到 Agora 的讀取視圖：讀取 manifest 被拒（無 Agora 讀取權）: 找不到檔案 (HTTP 404): PLACEHOLDER-MANIFEST-FILE-ID
[skill] 這是 fail-closed：不能確認內容有沒有進去，就不會寫任何東西。請先讓提交流程發佈讀取視圖（6.3 健康檢查）。
RC=5
```

> 這裡補了一個修正：`AccessDenied` 原本會以 traceback 的形式回給模型
> （plugin 把 stderr 原樣帶回）。現在是 exit code 5 ＋兩行說明。

`whoami` 不需要讀取視圖，所以正常：

```
$ docker exec syncer-2 python -m aistorage.skill whoami --session ses_f1a9f0261ffesKF2afZ2iONva0
{"is_main": true, "parent_id": null, "session_id": "opencode:ses_f1a9f0261ffesKF2afZ2iONva0"}
```

## 4. 這一輪抓到並修掉的兩個問題

### 4.1 「秘密沒有出現在 /work」是**假通過**（5.1 證據的結論要更正）

`verify-boundary.sh` 原本寫 `for f in "${SECRETS_DIR}/*"`，但 `/secrets` 是
`0711`（可穿越、不可列目錄）→ glob 不展開 → 迴圈一個檔案都沒掃到 →
`secret_leak_hits` 必然是 0。**5.1 證據裡記的「0 命中」因此無效**（已加更正註記）。

修法：照白名單逐檔指名，並新增 `secret_leak_scanned`（實際掃過幾個檔案），
掃過 0 個就算失敗。反向驗證（把 `signing.key` 複製到 `/work`）：

```
── 秘密值在 /work 裡的命中數: 1（rclone-worker.conf=0 sa-reader.json=0 signing.key=1 llm-opencode.key=0）
```

順帶修掉第二個問題：`grep -F -f` 會把 pattern 檔裡的**短行**也拿去比對，
`sa-reader.json` 有一行是單字元，於是 `/work` 底下 opencode 裝的 `node_modules`
裡幾千個 JSON 全部「命中」（實測 291,964）。現在只取長度 ≥ 12 的行當 pattern；
`reader.json` 不參與掃描（它是非秘密的讀取設定，內容是通用 JSON 鍵，會撞到
`/work/schemas/identity-registry.schema.json`）。

### 4.2 讀取端 fail-closed 會以 traceback 回給模型

`AccessDenied` 原本從 `python -m aistorage.skill` 漏成未捕捉例外，plugin 會把整份
traceback 帶回給 AI。現在是 exit code 5 ＋兩行說明（見第 0 節）。
