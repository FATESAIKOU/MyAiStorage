## 1. 四個 conf 的 about（授權與配額）

指令（四個 conf 各一次，`RCLONE_CONFIG` 只指路徑）：

```bash
for c in committer mac-opencode test-profile other-project; do
  RCLONE_CONFIG="$HOME/.config/aistorage-spike/rclone-$c.conf" rclone about gdrive:
done
```

四個輸出完全相同（rc=0）：

```
Total:   5 TiB
Used:    4.342 MiB
Free:    3.825 TiB
Trashed: 234 B
Other:   1.175 TiB
```

Drive API `about.get` 佐證（committer conf；只取非秘密欄位）：

```json
{"limit": "5497558138880", "usage": "1292318210540",
 "usageInDrive": "4552943", "usageInDriveTrash": "384"}
```

- `limit` = 5497558138880 bytes = **5 TiB 整**（家庭共用的 5TB 方案），不是 15 GB 個人免費額度 → 配額判準 pass。
- `usage` 約 1.175 TiB（專用帳號的總用量，含 Drive 以外的 Google 服務）、`usageInDrive` 約 4.3 MiB（Drive 本身）；兩者都算在共用的 5 TiB 池。

## 3. `root_folder_id` 生效（H6）

```bash
# committer conf：gdrive: 的根 = SPIKE_FOLDER_ID
rclone lsf gdrive: --config "$CFG"                          # 空（當時只有稍早的 smoke 殘留，亦在此步前後清理）
# 真正的 My Drive root：
rclone lsf gdrive: --drive-root-folder-id root --config "$CFG"
# → (0).jpg … テスト/  aistorage-spike/  aistorage-spike-smoke-*/
```

對照實驗（建 `committer-root-check.txt`）：

- `rclone lsf gdrive:` → 看到 `committer-root-check.txt`
- `rclone lsf gdrive: --drive-root-folder-id root` → **看不到**該檔（只看到 `aistorage-spike/` 資料夾本身）

→ `root_folder_id = SPIKE_FOLDER_ID` 生效：committer 的相對路徑都在 `aistorage-spike/` 底下，且 `rclone lsf gdrive:` 列出的就是 `SPIKE_FOLDER_ID` 的內容（此步時為空）。

## 4. 同意畫面狀態與自建 client（非 rclone 內建）

- Console「目標對象」為「**正式版**」：由使用者依 `docs/spike/setup.md` A.2 設定（發布應用程式、不送驗證）；PM 於 `docs/resources.md` 記為「OAuth client（電腦版，正式版發布、未驗證）」，本檔沿用該記錄。**此狀態無法由 API 驗證**，判定依 Console 狀態＋後續 refresh 行為（見「token 期限」）。
- 四個 conf 都設了自建 `client_id`（逐一檢查 conf 有 `client_id =` 行），且四個 client_id 兩兩互異（以尾碼比對，不記值）。
- rclone 執行時 stderr 無任何 `built-in`／`shared client`／`will stop working`／`deprecated` 類警告（四個 conf 各跑一次 `rclone lsd gdrive:` 檢查 stderr）。
- → 不是 rclone 內建 client；無內建 client 停用警告。

## 5. Token 期限（今日基準）

以四個 conf 的 refresh token 對 `oauth2.googleapis.com/token` 換 access token（token 只進 HTTP body、不落檔、不印出），四個都是：

```
refresh HTTP 200  scope=<drive 或 drive.file>  expires_in=3599  token_type=Bearer
```

- committer：`scope=https://www.googleapis.com/auth/drive`；其餘三個：`.../auth/drive.file`（與 setup 的設計一致）。
- 首次授權時間（conf 檔案建立時間，metadata）：committer 2026-09-26 06:12 UTC；mac-opencode 07:25 UTC 前後；test-profile／other-project 07:26 UTC 前後。
- **M2 caveat**：驗證期不到 7 天，本次無法驗「7 天 refresh token 過期」。依 test-plan：1.9 以 Console 正式版狀態判定為 pass-with-caveat，並排「首次授權後第 8 天」（**2026-10-04 前後**）的複查；複查失敗再回頭處理，不擋 go。
