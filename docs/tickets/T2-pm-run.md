## 發現（都是 Low，不擋歸檔）

| # | 內容 |
|---|---|
| Q1 | 確認視窗裡的勾選框一律畫成 `X`，勾了沒勾只差顏色；下面那行說明（「雲端沒有的會印一行提醒，本機的不動」）也不會跟著變。建議說明跟著狀態換，或用 `[ ]`／`[x]` |
| Q2 | delete 的確認視窗寫「Enter 確定」，但 Enter 是「選目前停的那一個」（預設是取消）；容易讀成「Enter＝確定」。建議寫成「Enter 選擇」 |
| Q3 | 進度條顯示的是「開始做第 k 個」：寫第 1 個要約時就是 50%，寫第 2 個時已經 100%，看起來像卡在 100% |
| Q4 | 結果視窗之後，下面的狀態列還留著上一次的「已中斷；重跑同一個動作會接著做」 |
| Q5 | 一次送出 `a` 和 `enter` 兩個鍵時（同一次 send-keys），只匯入了游標那一列；分開按就正常。沒有再重現，可能是終端機一次收到兩個鍵時的時序，記下來 |
| Q6 | 雲端沒有（✗）的 Session，它原本的 agent session 會重新出現在未匯入頁（因為 import 會建新的）；符合 spec，但使用者可能會以為還沒匯入過 |
| Q7 | merge 被中斷時，輸出的最後一行是 continue 的說法（「沒存完的接續會在下一個 agora 指令自動補存」），同 T1 PM 驗收的 P4 |
