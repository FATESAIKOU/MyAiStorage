## MODIFIED Requirements

### Requirement: 按鍵
按鍵分成兩套，依焦點在清單（左）還是預覽區（右）而不同。

兩邊共用的 MUST 只有兩個：
- `Tab`（`shift+tab` 也一樣）：在清單與預覽區之間切換焦點；
- `q`：離開。

焦點在清單時，按鍵 MUST 是：
- ↑↓ 移動；
- `[`、`]` 換頁（Agora／未匯入）；
- 空白勾選，`a` 全選切換；
- `/` 篩選，ctrl+t 切換標題與內文；
- Enter（Agora 頁接續、未匯入頁匯入）；
- `m` 合併、`e` 改標頭、`d` 刪除、`p` pull、`P` push。

焦點在預覽區時，按鍵 MUST 是「預覽區的游標與捲動」與「預覽區搜尋」規定的那些。清單的鍵 MUST NOT 在預覽區生效，預覽區的鍵也 MUST NOT 在清單生效。

等待視窗與確認視窗裡的按鍵照舊（Esc 中斷或取消）。

按鍵列 MUST 只顯示目前能用的鍵，並跟著焦點換。

#### Scenario: 未匯入頁的按鍵列
- **WHEN** 在未匯入頁、焦點在清單
- **THEN** 按鍵列沒有 `m`、`e`、`d`、`P`

#### Scenario: Tab 切焦點、[ ] 換頁
- **WHEN** 焦點在清單，按 `Tab`
- **THEN** 焦點移到預覽區，頁面不變；再按 `]`，什麼都不發生；再按 `Tab` 回到清單，按 `]` 才換到下一頁

#### Scenario: 預覽區按清單的鍵
- **WHEN** 焦點在預覽區，按 `d`
- **THEN** 不會開刪除的確認視窗

## ADDED Requirements

### Requirement: 預覽區的游標與捲動
預覽區 MUST 以唯讀方式顯示原始的 Markdown，並加上語法上色。

預覽區 MUST 有游標，游標所在的那一行整行高亮。焦點在預覽區時：
- `j`、`↓` 往下一行，`k`、`↑` 往上一行；
- `g` 到最前面，MUST 先把還沒載入的部分全部載入；
- `G` 到最後一行。

游標移到已載入內容的第一行、再往上時，MUST 照 T6 的規則載入前一段並補在上面，游標停在原本那一行，不跳。換到另一個 Session 時，游標 MUST 在最後一行。

#### Scenario: 游標移動
- **WHEN** 焦點在預覽區，按 `k` 三次
- **THEN** 游標在倒數第四行，該行整行高亮

#### Scenario: 到最前面
- **WHEN** 一個還有更早內容沒載入的大 Session，在預覽區按 `g`
- **THEN** 全部載入，游標在第一行，「↑ 往上捲載入更早的內容」那一行消失

### Requirement: 預覽區搜尋
焦點在預覽區時，`/` MUST 打開搜尋框。

輸入文字並按 Enter 後：
- MUST 在**整份 Session**（包含還沒載入的部分）找出所有符合（不分大小寫）；
- 游標 MUST 跳到離目前位置最近的下一個符合；
- 所有已載入的符合 MUST 標亮；
- MUST 顯示「第 k 個／共 N 個」。

之後：
- `n` MUST 跳到下一個，`N` MUST 跳到上一個，到頭時繞回另一端；
- 要跳到的符合還沒載入時，MUST 先載入到包含它的那一段，再跳過去；
- `Esc` MUST 清掉標亮與計數，游標留在原地。

找不到時 MUST 說「找不到」，游標不動。搜尋 MUST NOT 把整份檔案排版或一次放進預覽區；只讀檔案找位置，載入照 T6 的規則一段一段來。

#### Scenario: 找到並跳過去
- **WHEN** 焦點在預覽區，按 `/`，打 `表格`，按 Enter
- **THEN** 游標跳到下一個「表格」，所有已載入的「表格」標亮，顯示「第 1 個／共 N 個」

#### Scenario: 跳到還沒載入的地方
- **WHEN** 一個 2 MB 的 Session 只載入了最後一段，搜尋的字只出現在最前面，按 `n`
- **THEN** 載入到包含它的那一段，游標跳到那裡，畫面上看得到它

#### Scenario: 清掉標亮
- **WHEN** 有搜尋標亮時按 `Esc`
- **THEN** 標亮與計數消失，游標不動，焦點仍在預覽區
