# MyAiStorage

AiStorage：個人 AI 基礎建設中「狀態」那一層，把系統該記住的東西外部化到所有執行體之外。它由四個各自獨立的儲存要素組成：MyBrain、Atelier、Agora、Foundry。

接手或第一次來，依序讀：

1. `REQ.md`：背景、目的、步驟、限制（交接用）
2. `CONTEXT.md`：術語表
3. `docs/adr/`：架構決定
4. `openspec/changes/establish-aistorage-phase1/`：期 1 的 proposal、specs、design、tasks

目前狀態：需求設計與基本設計已經完成（2026-09-26 重定期 1：驗證 Session 的分裂、統合、相互參照），實作還沒開始（tasks 第 1 組「技術驗證」是閘門）。期 1 之外的事項在 `docs/backlog.md`。
