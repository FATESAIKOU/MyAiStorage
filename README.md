# MyAiStorage

AiStorage：個人 AI 基礎建設中「有狀態的資料」那一層。它由四個各自獨立的儲存要素組成：MyBrain、Atelier、Agora、Foundry。

接手或第一次來，依序讀：

1. `REQ.md`：背景、目的、步驟、限制（交接用）
2. `CONTEXT.md`：術語表
3. `docs/adr/`：架構決定
4. `openspec/changes/establish-aistorage-phase1/`：期 1 的 proposal、specs、design、tasks

目前狀態：需求設計與基本設計已經完成，實作還沒開始（tasks 第 1 組「技術驗證」是閘門）。
